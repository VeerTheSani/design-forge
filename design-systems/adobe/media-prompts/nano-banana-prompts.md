# Nano Banana Visual & Image Generation Playbook (ADOBE Design System)

> **Purpose:** Every Bento card, hero composite, and feature showcase on **adobe** relies on strict art-direction rules (focal placement, negative space for text overlays, studio lighting, and vibrant color harmony). Use these slot-matched prompts in **Nano Banana** to generate drop-in visuals for any new website built with this design system.

---

## Core Visual DNA Extracted from adobe

1. **Subject-to-Negative-Space Ratio (60/40 Rule):** Cards in adobe's Bento grid place the typography directly *inside* the card padding (`32px` to `40px`). Therefore, every generated image must reserve **35%–40% negative space** (usually at the top or left) with a smooth tonal gradient.
2. **Tactile Hyper-Clarity:** Combines photorealistic studio lighting with surreal 3D/glass/iridescent accents—avoiding flat stock-photo aesthetics.
3. **Color Anchoring:** High-saturation focal subjects set against deep obsidian (`#0E0E12`), warm alabaster (`#F5F5F7`), or rich gradient backdrops.
