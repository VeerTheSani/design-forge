# Google Flow Motion & Video Agent Prompt Playbook (ADOBE Design System)

> **Purpose:** This file maps every motion/video container extracted from **adobe** so you can hand exact, camera-directed, composition-safe prompts to the **Google Flow Agent** when building a new website on top of this Design System.

---

## Why adobe's Motion Containers Look Professional (Extracted Rules)

1. **Luminance Safe Zones for Typography:** Video backgrounds on adobe never put high-frequency bright noise behind the H1/H2 text region. The **upper-left 45%** (for split heroes) or **top-center 40%** (for Bento cards) maintains controlled contrast so crisp white or dark typography stays 100% legible without muddy overlays.
2. **Continuous Seamless Micro-Motion:** Loops run between **6s and 10s**, `muted autoplay loop playsinline`, using slow dolly-in, orbital parallax, or fluid material morphing—never jarring jump cuts.
3. **Interactive Pause/Play Physics:** Every video container includes a glassmorphic `backdrop-filter: blur(16px)` pill toggle in the bottom-right corner and triggers smooth `scale(1.045)` zoom on card hover.
